# stock-prices

국내·해외 주식 시세를 주기적으로 받아 `prices.json` 으로 남겨두는 저장소입니다.

브라우저는 보안 규칙(CORS) 때문에 증권 사이트를 직접 읽을 수 없습니다.
파이썬에는 그 제약이 없어서, 깃허브 액션에서 시세를 받아 파일로 저장해두고
웹 페이지는 그 파일만 읽어가면 됩니다. 별도 서버가 필요 없습니다.

담기는 것은 **종목 코드와 시세뿐**입니다.

## 구성

| 파일 | 하는 일 |
|---|---|
| `fetch.py` | 시세를 받아 `prices.json` 을 만든다 |
| `tickers.json` | 종목 목록 (KOSPI · KOSDAQ · NASDAQ) |
| `watchlist.txt` | 해외 종목 중 시세를 받아올 것 |
| `prices.json` | 결과 |
| `.github/workflows/prices.yml` | 자동 실행 설정 |

## 언제 도는지

한국 장중(09:00~15:30)에 10분마다, 장 마감 뒤 한 번 더 돕니다.
깃허브 예약 실행은 상황에 따라 밀릴 수 있어 **실제로는 10~30분 전 시세**입니다.

`Actions` 탭에서 `Run workflow` 로 직접 돌릴 수도 있습니다.

## 해외 주식

국내는 2,600여 종목을 한 번에 받아오므로 따로 설정할 게 없습니다.

해외(나스닥)는 종목마다 따로 요청해야 해서 필요한 것만 받습니다.
`watchlist.txt` 에 한 줄씩 적어주세요.

```
AAPL    # 애플
NVDA    # 엔비디아
```

## 결과 형식

```json
{
  "updated": "2026-07-28 07:12",
  "count": 2597,
  "prices": { "005930": 254000.0, "000660": 1816000.0 }
}
```
